# Spring Data JPA Book Repository\n\nTask: create a Book repository, save and retrieve a Book in a JUnit test, run using H2, then commit to Git.\n\n## Test\nRun in terminal: `mvn test -Ph2` and verify BUILD SUCCESS.\n\n## Run app\n`mvn spring-boot:run -Ph2` then open http://localhost:8080/books. POST JSON example: `{"title":"Clean Code","author":"Robert C. Martin"}`. H2 console: http://localhost:8080/h2-console (JDBC URL `jdbc:h2:mem:testdb`, user `sa`, blank password).\n\n## Git commit\n`git init`\n`git add .`\n`git commit -m "Add Spring Data JPA Book repository and test"\n
